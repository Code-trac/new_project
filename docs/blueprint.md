# **App Name**: SkillSwap Connect

## Core Features:

- Home Page: Home page with a brief description of the platform.
- Login Page: Login page for students and teachers with role selection (dropdown menu).
- Search Functionality: Search feature to find teachers and subjects, and/or students with desired skills.
- Teacher Rating: Credit/rating feature for teachers; students can rate teachers (persistent storage required).
- User Dashboard: User dashboard to view and edit their profile.

## Style Guidelines:

- Primary color: Clean white or light grey background.
- Secondary color: A calming blue (#3498db) for headers and accents.
- Accent color: Green (#2ecc71) for buttons and interactive elements, indicating positive actions.
- Clear and readable font for body text.
- Simple and intuitive icons for navigation and actions.
- Clean and organized layout with clear sections.
- Subtle hover effects on interactive elements.
